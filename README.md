# Sofía Cominelli — Academic website

A responsive academic website for GitHub Pages. Built with plain HTML and CSS; no installation or build step required.

## Publish on GitHub Pages

1. Create a **public** repository named **SCominelli.github.io** in the SCominelli account.
2. Upload the contents of this folder to the repository root. Keep the `assets` directory intact. Upload `index.html` directly to the root, not inside an additional folder.
3. In **Settings → Pages**, choose **Deploy from a branch**, then **main** and **/ (root)**. Save.
4. Once deployment completes, open https://scominelli.github.io/ .

## Edit the website

- `index.html`: introduction and interests.
- `research.html`: research and funding.
- `publications.html`: publications and conference presentations.
- `experience.html`: education and professional experience.
- `teaching.html`: teaching, leadership, awards, and service.
- `cv.html`: online CV.
- `assets/CV_Sofia_Cominelli.pdf`: downloadable public CV.
- `assets/style.css`: colors, typography, layout, and mobile styles.

Content is based on the supplied 2026 CV. Home address and telephone are omitted from the public version. Publication statuses have not been independently updated. The SC monogram can be replaced with a portrait later.

Open `index.html` locally to preview, or run `python3 -m http.server 8000` in this folder and visit http://localhost:8000 .
